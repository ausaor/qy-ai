# 向系统用户发送问候邮件

## 概述

通过青语（项目名称）向系统注册用户发送一封温馨的问候邮件。
发件邮箱固定使用项目配置文件（spring.mail.username）中的邮箱，发件人名称固定为「聴夏」。

## 强制规则

1. 收件人校验（发送前必须完成，以下两条路径均强制）：
   - 用户提供姓名/昵称（如"向 Spring 发送问候"）：必须先调用 verifyRecipient 工具按用户名/昵称查询系统用户表，
     确认该用户存在且状态正常（未删除、未封禁、未禁用），并获得其注册邮箱；查无此人时禁止发送并明确告知用户。
   - 用户直接提供邮箱：必须先调用 verifyRecipient 工具校验该邮箱在系统用户表中已注册；
     未注册时禁止发送并明确告知用户。
2. 禁止猜测或编造收件邮箱：任何情况下都不得使用未经 verifyRecipient 校验通过的邮箱发送邮件。
3. 邮件正文必须使用项目 templates 目录下的问候邮件 HTML 模版（greeting-email.html）。
   模版内已包含项目名称「青语」与发送人「聴夏」，不得自行构造邮件内容替代模版。
4. 发送动作必须通过调用 sendGreetingEmail 工具完成；只有工具返回"发送成功"后，才可告知用户"邮件已发送"，
   严禁未调用工具就声称已发送，严禁编造发送结果。
5. 发件邮箱与发件人名称由系统固定配置（spring.mail.username / 聴夏），任何情况下不得更改。
6. 问候语内容要求：简洁、温馨、正向，一两句话即可；可结合用户意图或节日/场景生成，
   禁止包含广告、营销链接或不雅内容。

## 标准流程

1. 解析收件人：区分"按姓名/昵称"还是"按邮箱"。
2. 调用 verifyRecipient 校验 → 校验通过则进入下一步；失败则终止流程并如实告知用户校验结果。
3. 生成问候语（简洁温馨）。
4. 调用 sendGreetingEmail 发送邮件。
5. 根据工具返回结果向用户汇报（发送成功或失败原因）。
